# Digital Ledger System (Admin-Based)

## 📌 Project Overview
This project is an admin-only digital ledger system designed for small shops and service providers.  
It helps shop owners track customers, unpaid balances (debts), store credits, stock, and transaction history in one clear and reliable place.

The system replaces manual notebooks, scattered records, and memory-based tracking with a structured digital solution.

---

## ❓ Problem Statement
Many small businesses allow customers to pay later or leave extra money as store credit.  
These transactions are often tracked using paper notebooks, WhatsApp messages, or informal methods, which leads to:
- Lost or incorrect records
- Confusion about who owes what
- No clear transaction history
- Poor stock visibility

This project aims to solve these issues by providing a simple and organized digital ledger.

---

## ✨ Planned Features
- Admin-only authentication (shop owner access)
- Customer management
- Debt and payment tracking
- Store credit management
- Full transaction history
- Stock tracking (in / out)
- English and Arabic language support
- Excel export for reports (customers, transactions, stock)
- Email and WhatsApp notifications

---

## 🛠 Tech Stack
- **Backend:** PHP (Laravel)
- **Database:** PostgreSQL
- **Authentication:** Laravel built-in authentication
- **Localization:** Laravel localization (EN / AR)
- **Exports:** Excel file generation
- **Version Control:** Git & GitHub
- **Project Management:** Jira
